# Электронное портфолио студентов 1 курса — KleverDi

Готовый frontend-сайт для студентов. Данные сохраняются в браузере, а после подключения Google Apps Script кнопка «Отправить портфолио» отправляет результат преподавателю в Google Sheets.

## Один обязательный шаг перед выдачей ссылки студентам
1. Откройте таблицу «Портфолио для студентов».
2. Расширения → Apps Script.
3. Вставьте код из `google-apps-script/Code.gs`.
4. Deploy / Развернуть → New deployment / Новое развертывание → Web app.
5. Execute as: Me. Access: Anyone.
6. Скопируйте URL вида `https://script.google.com/macros/s/.../exec`.
7. В `js/config.js` вставьте этот URL в `COLLECTOR_URL`.
8. Загрузите папку сайта на любой статический хостинг.

После этого студентам даётся только ссылка на сайт. Они заполняют разделы и нажимают «Отправить портфолио».

## Важно
Без Web App URL браузер не может напрямую записывать данные в приватную Google Таблицу.
